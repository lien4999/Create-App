# Google Play Console Automation & Creator Platform

نظام متكامل يحاكي واجهة **Google Play Console** الرسمية بالكامل لإنشاء التطبيقات، مع محرك أتمتة خلفي (Automation Engine) مدعوم بـ **Playwright** للربط التلقائي بحساب المطور المؤسسي.

---

## 📁 هيكلية المشروع

```text
Create App/
├── public/
│   ├── index.html        # واجهة صفحة "إنشاء تطبيق" المطابقة لـ Google Play Console
│   ├── styles.css        # نظام التصميم Material Design 3 باللغة العربية (RTL)
│   └── app.js            # المنطق التفاعلي، فحص الحزمة، وربط الأتمتة
├── server/
│   ├── server.js         # خادم الويب وواجهة API (Express)
│   ├── automation.js     # محرك الأتمتة الرئيسي لـ Playwright
│   ├── session-setup.js  # سكربت تسجيل الدخول لمرة واحدة وحفظ الجلسة
│   ├── package-checker.js# سكربت فحص توفر اسم الحزمة على المتجر
│   └── session.json      # ملف الجلسة المحفوظ (يتم إنشاؤه بعد تسجيل الدخول)
├── package.json          # الاعتماديات والأوامر
└── README.md             # دليل التشغيل والرفع
```

## 🚀 التشغيل السريع على جهازك المحلي

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تسجيل الدخول وحفظ الجلسة (لمرة واحدة فقط):
```bash
npm run setup-session
```
* سيفتح المتصفح صفحة تسجيل الدخول لـ Google Play Console.
* سجّل الدخول بحساب المطور المؤسسي الخاص بك وأكمل التحقق بخطوتين (2FA).
* سيقوم السكربت تلقائياً بحفظ ملف تعريف الجلسة في `server/session.json`.

### 3. تشغيل الخادم والموقع:
```bash
npm start
```
* افتح المتصفح على: `http://localhost:3000`
* ستجد الواجهة جاهزة بالكامل ومطابقة للكونسول.

## 🔒 حماية حساب المطور المؤسسي

لأن حسابات Google Play حساسة للغاية لأي تطبيق مخالف للسياسات:
1. **قائمة مراجعة داخلية (Approval Queue):** يفضل عدم النشر الفوري لأي شخص بدون موافقة إدارية بنقرة واحدة من لوحة تحكمك.
2. **فحص الـ Package Name تلقائياً:** مدمج حالياً لمنع تكرار أسماء الحزم.
3. **مفتاح الخدمة الرسمي (Google Play API):** بعد أن يقوم Playwright بإنشاء التطبيق الأساسي، استخدم Google Play Developer API لرفع ملفات `.aab` عبر سيرفر آمن.
